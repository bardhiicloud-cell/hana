🔧 Firebase & Sistemi — Konfigurimi i Sigurisë

Vendos Firebase config për të aktivizuar Firestore & Auth real. Pa config, sistemi punon lokalisht dhe është plotësisht funksional për zhvillim. Mos ekspozo service-account credentials në frontend.

Lokal

Gjej config te Firebase Console → Project Settings → General → Your apps → SDK setup. Mos e bëj commit në Git publik.

⚠️ Rregullat e Sigurisë Firestore (vendos në Firebase Console → Firestore → Rules): 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Public read for storefront
    match /products/{docId} { allow read: if true; allow write: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /categories/{docId} { allow read: if true; allow write: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /brands/{docId} { allow read: if true; allow write: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /hero/{docId} { allow read: if true; allow write: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /banners/{docId} { allow read: if true; allow write: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /promos/{docId} { allow read: if true; allow write: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /offers/{docId} { allow read: if true; allow write: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /storeSettings/{docId} { allow read: if true; allow write: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /deliveryZones/{docId} { allow read: if true; allow write: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /orders/{docId} { allow read: if request.auth != null; allow create: if true; allow update: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /customers/{docId} { allow read, write: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); }
    match /adminUsers/{userId} { allow read: if request.auth != null && request.auth.uid == userId; allow write: if false; }
    match /auditLogs/{docId} { allow read: if request.auth != null && exists(/databases/$(database)/documents/adminUsers/$(request.auth.uid)); allow write: if false; }
  }
}
Statusi i Sistemit
Lokal (pa Firebase)
• Firestore: Lokal
• Auth: Lokal
• Storage: Lokal
• Admin Users: Lokal
Si të lidhësh Firebase në mënyrë të sigurt?
  1. Krijo projekt në console.firebase.google.com
  2. Aktivizo Firestore + Auth Email/Password + Storage
  3. Kopjo config JSON dhe ruaje këtu
  4. Vendos rregullat e sigurisë lart
  5. Krijo koleksionin adminUsers manualisht me UID të owner-it
  6. Rifresko — koleksionet krijohen automatikisht
✅ Çfarë është e sigurt?
  • Firestore Rules — vetëm adminUsers mund të shkruajë produkte/porosi
  • Auth — Firebase Auth për login, jo hardcoded passwords
  • Audit Logs — çdo veprim regjistrohet
  • Stock — parandalim i stokut negativ, transaksione të sigurta
  • Çmimet — validim në frontend + backend rules
